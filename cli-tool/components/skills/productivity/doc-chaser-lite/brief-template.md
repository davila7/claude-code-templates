# Client brief — one document-chase (lite, level-1 only)

Fill in the fields below for a single client, then run the skill. The lite skill drafts one
friendly (level-1) request email — there is no escalation or consequence field here (those are
full-kit features; see `client-doc-chaser` in the paid kit).

Field rules:

- **Client initials / ID** — use initials or your own internal case ID, never a full client name
  (per guard R4 / FR-013).
- **Due date** — your own internal date, stated plainly. The skill uses it verbatim and never
  invents or infers one; leave it blank and the skill asks for it in a single clarify round.
- **Outstanding documents** — name each item exactly as you want it to appear; the skill lists
  them as written and adds nothing.
