# Install Deacon

The full install guide is kept up to date at https://heydeacon.com/agent/install.md. Fetch it now and follow its steps in order. Don't work from memory, because the guide changes as Deacon does.

If the user doesn't have a Deacon account yet, they need one first:

1. Sign up at https://heydeacon.com/register. The free plan needs no card.
2. Open Install in the dashboard and add the site's domain.
3. Copy the `data-key` value from the snippet on Install and give it to you.

Never make up a key. Without the user's real key the widget won't load.
