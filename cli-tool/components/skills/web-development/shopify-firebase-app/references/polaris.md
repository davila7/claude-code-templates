# Polaris web components

_From [Nitrogen](https://github.com/mksd0398/nitrogen), where it is generated from `tools/reference/`._

Every component a Nitrogen page can use, each with a working example. They are custom elements loaded by `<script src="https://cdn.shopify.com/shopifycloud/polaris-1.js">` in `web/*.html`: plain HTML, no React, no build step, no imports. Polaris React (`<Page>`, `<Card>`, `@shopify/polaris`) does not apply here. Inside an app, the same examples render live on its Components page (`web/polaris.html`).

- **[Actions](polaris-actions.md):** Button, Button group, Clickable, Clickable chip, Link, Menu
- **[Feedback and status](polaris-feedback-and-status.md):** Badge, Banner, Empty state, Progress, Spinner
- **[Forms](polaris-forms.md):** Text field, Text area, Email field, Password field, Number field, Money field, URL field, Search field, Select, Checkbox, Switch, Choice list, Color field, Color picker, Date field, Date picker, Drop zone
- **[Layout and structure](polaris-layout-and-structure.md):** Page, Section, Box, Stack, Grid, Query container, Divider, Table, Ordered list, Unordered list
- **[Media and visuals](polaris-media-and-visuals.md):** Avatar, Icon, Image, Thumbnail
- **[Overlays](polaris-overlays.md):** Modal, Popover
- **[Typography and content](polaris-typography-and-content.md):** Heading, Paragraph, Text, Number, Chip, Tooltip

Each group is in its own file, linked above.
