PostgreSQL DBA Agent for Claude Code: Inspect, Query and Tune Your Database

A focused subagent that talks to your database through real tools instead of guessing from your codebase.

5 min read
Claude Code Agents PostgreSQL Database SQL

Installation

Install the agent with the Claude Code Templates CLI:

npx claude-code-templates@latest --agent data-ai/postgresql-dba

The command downloads postgresql-dba.md into your project's .claude/agents/ folder. Claude Code picks up new agent files automatically; you can also manage them from the /agents menu.

Prerequisite: the agent's tools come from the ms-ossdata.vscode-pgsql VS Code extension (PostgreSQL by Microsoft). Use it from a Claude Code session inside VS Code with that extension installed and a server connection configured.

What the Agent Does

PostgreSQL DBA is a subagent: a Markdown file with YAML frontmatter (name, description, tools) whose body is the system prompt. It frames Claude as a PostgreSQL database administrator able to create and manage databases, write and optimize SQL, run backups and restores, monitor performance and apply security measures.

Its distinguishing rule is the last line of the prompt: always use the tools to inspect the database, never look into the codebase. The answer comes from the live schema, not from guessing at ORM models.

The Tools It Is Allowed to Use

The frontmatter restricts the agent to an allowlist. The database-specific ones are:

ToolPurpose
pgsql_listServers, pgsql_connect, pgsql_disconnectFind, open and close a server connection
pgsql_listDatabases, pgsql_modifyDatabaseList databases and change them
pgsql_queryRun SQL
pgsql_visualizeSchemaDraw the schema
pgsql_describeCsv, pgsql_bulkLoadCsvInspect and bulk-load CSV files
pgsql_open_scriptOpen a SQL script in the editor

It also keeps general tools such as codebase, edit/editFiles, githubRepo, extensions and runCommands.

Step-by-Step Workflow

A concrete task: find out why an orders report is slow.

1. Install and open the project

Run the install command, open the project in VS Code, and connect to your server in the PostgreSQL extension.

2. Invoke the agent

Claude can delegate automatically based on the agent's description, but to be certain, ask for it by name:

Use the postgresql-dba agent to list my databases and show the schema of the orders database.

On start, the prompt tells it to verify the extension is installed and to ask you to install it if it is missing.

3. Inspect before you change anything

Use the postgresql-dba agent to describe the orders and order_items tables and check which indexes exist.

4. Diagnose the query

Use the postgresql-dba agent to run EXPLAIN ANALYZE on the monthly revenue query and suggest an index.

5. Review, then apply

Ask for the CREATE INDEX statement and read it before it runs. Because the agent can call pgsql_query and pgsql_modifyDatabase, point it at a development or staging database first.

Tuning and Caveats

Heads up: this agent was written around the VS Code PostgreSQL extension's tool names. Where those tools are not available, the pgsql_* entries have nothing to call, so check that it can reach your database before relying on it. Never connect it to production with write access you would not give a colleague.
  • Edit the tools line in .claude/agents/postgresql-dba.md to remove pgsql_modifyDatabase or pgsql_bulkLoadCsv for a read-only setup.
  • Add a model field to the frontmatter if you want a specific model for database work.

Conclusion

PostgreSQL DBA is a small file with a clear rule: look at the real database. Install it with one command, connect through the extension, and use it for schema inspection, query tuning and routine administration.
