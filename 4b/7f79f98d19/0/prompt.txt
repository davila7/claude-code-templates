I've researched the official Claude Code documentation and compiled a comprehensive guide to configure Claude Code for maximum conciseness. Here's the complete structured list:

---

## **OUTPUT STYLES**

| Name | How to Set | Value | Effect |
|------|-----------|-------|--------|
| **Concise** output style | `/config` → Output style, OR `outputStyle` in settings.json | `"Concise"` | Skips preamble, leads with results, keeps responses short by default. Still provides full explanations when requested. ✓ **MOST IMPACTFUL** |

**Set in `~/.claude/settings.local.json` or `.claude/settings.local.json`:**
```json
{
  "outputStyle": "Concise"
}
```

---

## **SETTINGS.JSON OPTIONS**

### Disable Tips &amp; Notifications

| Setting Path | Value | Effect |
|--------------|-------|--------|
| `spinnerTipsEnabled` | `false` | Hide tips shown during the spinner animation |
| `awaySummaryEnabled` | `false` | Disable one-line recap when returning to terminal after being away |

### Minimize Display

| Setting Path | Value | Effect |
|--------------|-------|--------|
| `autoScrollEnabled` | `false` | In fullscreen mode, don't auto-follow output to bottom (manual scrolling) |
| `axScreenReader` | `true` | Render flat text without decorative borders or animations (accessibility/minimal mode) |
| `verbose` | `false` | Disable verbose output (set via `/config verbose=false` from v2.1.181+) |

### Context Management (Keep Enabled)

| Setting Path | Value | Effect |
|--------------|-------|--------|
| `autoCompactEnabled` | `true` *(default)* | **Keep ON** — auto-compacts conversation when context fills; saves tokens |
| `autoCompactWindow` | `300000` to `500000` | Compact earlier (smaller number = earlier compacting); saves tokens by reducing context |

**Complete minimal settings.json:**
```json
{
  "outputStyle": "Concise",
  "spinnerTipsEnabled": false,
  "awaySummaryEnabled": false,
  "autoScrollEnabled": false,
  "axScreenReader": false,
  "verbose": false,
  "autoCompactEnabled": true,
  "autoCompactWindow": 300000
}
```

---

## **CLI FLAGS** (For Launch)

| Flag | Usage | Effect |
|------|-------|--------|
| `-p` / `--print` | `claude -p "query"` | Non-interactive mode; prints result and exits (no interactive UI overhead) ✓ |
| `--bare` | `claude --bare -p "query"` | Skip hooks, skills, CLAUDE.md, MCP servers, plugin discovery for faster startup |
| `--output-format text` | `claude -p "query" --output-format text` | Plain text output (default); most concise |
| `--output-format json` | `claude -p "query" --output-format json` | Structured JSON (good for scripting, not interactive) |
| `--ax-screen-reader` | `claude --ax-screen-reader` | Flat text rendering without decorations |

**Most concise CLI invocation:**
```bash
claude --bare -p "your prompt" --output-format text
```

---

## **ENVIRONMENT VARIABLES**

| Variable | Value | Where to Set | Effect |
|----------|-------|--------------|--------|
| `CLAUDE_AX_SCREEN_READER` | `1` | Shell / `~/.claude/settings.json` `env` section | Flat text without borders/animations; minimal rendering |
| `FORCE_HYPERLINK` | `0` | Shell / `~/.claude/settings.json` `env` section | Disable hyperlink rendering |
| `DISABLE_AUTO_COMPACT` | `1` | Shell / `~/.claude/settings.json` `env` section | **NOT recommended** — turns off context compacting (costly) |
| `CLAUDE_CODE_ARTIFACT_AUTO_OPEN` | `0` | Shell / `~/.claude/settings.json` `env` section | Don't auto-open artifacts in browser |

**Set in `~/.claude/settings.json`:**
```json
{
  "env": {
    "CLAUDE_AX_SCREEN_READER": "1",
    "FORCE_HYPERLINK": "0",
    "CLAUDE_CODE_ARTIFACT_AUTO_OPEN": "0"
  }
}
```

---

## **MODEL CONFIGURATION** (Affects Response Length)

| Command/Setting | Value | Effect |
|-----------------|-------|--------|
| Effort level | `--effort low` | Faster, shorter responses; less reasoning (best for simple tasks) |
| Effort level | `--effort medium` | Reduced token usage; good for cost-sensitive concise work |
| Fast mode | `--fast` or `/fast` | 2.5x faster responses on Opus; higher cost but snappier interaction |

**Set persistent effort in settings.json:**
```json
{
  "effortLevel": "medium"
}
```

**Launch with low effort:**
```bash
claude --effort low
```

## **CLAUDE.MD INSTRUCTION** (For Persistent Tone)

Add to `.claude/CLAUDE.md` or `.claude/settings.json` system prompt:

```markdown
## Claude Code Instructions

Keep responses terse and concise. 
- Lead with the result, not explanation
- Skip preamble and narration
- Use bullet points over paragraphs
- Provide full explanations only when explicitly requested
```

Or via CLI:
```bash
claude -p "query" --append-system-prompt "Keep responses terse and concise. Lead with results."
```

## **RECOMMENDED MINIMAL CONFIGURATION**

**For interactive sessions:** Set output style to "Concise", disable tips, use medium effort:
```bash
# Set once:
# ~/.claude/settings.json
{
  "outputStyle": "Concise",
  "spinnerTipsEnabled": false,
  "awaySummaryEnabled": false,
  "effortLevel": "medium"
}
```

**For scripts/CI:** Use bare mode with print:
```bash
claude --bare -p "task" --effort low --output-format text
```

**For fastest startup + minimal display:**
```bash
CLAUDE_AX_SCREEN_READER=1 FORCE_HYPERLINK=0 claude --bare -p "query"
```
